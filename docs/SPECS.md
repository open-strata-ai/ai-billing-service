## 1. API Contract

### 1.1 Transport & Conventions

| Aspect | Specification |
| --- | --- |
| Protocol | REST (Spring MVC + SpringDoc OpenAPI 3) |
| Base Prefix | `/api/v1` |
| Internal gRPC | `BillingQuery` for `ai-admin-service` (proto in `specs/`) |
| Auth Header | `Authorization: Bearer <JWT>` + `X-Tenant-Id` |
| OpenAPI | `openapi.yaml` auto-generated by SpringDoc |

### 1.2 API Endpoint Table

| Method | Path | Description | Auth Role |
| --- | --- | --- | --- |
| `POST` | `/usage` | Ingest metering (batch) | internal (metering service) |
| `GET` | `/tenants/{tenantId}/invoices` | Invoice list | tenant-admin |
| `GET` | `/tenants/{tenantId}/invoices/{id}` | Invoice detail | tenant-admin |
| `GET` | `/tenants/{tenantId}/cost` | Real-time cost profile | tenant-admin |
| `PUT` | `/tenants/{tenantId}/budgets` | Set budget | platform-admin |
| `GET` | `/tenants/{tenantId}/budgets` | Budget status | tenant-admin |
| `GET` | `/tenants/{tenantId}/allocations` | Department allocation (Showback) | tenant-admin |
| `POST` | `/reports:generate` | Trigger monthly settlement | platform-admin |
| `GET` | `/price-rules` | Current pricing table | authenticated |

### 1.3 HTTP Status Codes

| Code | Meaning |
| --- | --- |
| `2xx` | Success |
| `400` | Metering format invalid |
| `401` | Unauthenticated |
| `403` | Unauthorized (cross-tenant access) |
| `404` | Invoice/tenant not found |
| `409` | Duplicate settlement |
| `422` | Called in single-tenant mode (return `BILLING_REQUIRES_MULTITENANCY`) |
| `500` | Internal server error |

### 1.4 Error Response Schema

```json
{
  "code": "BILLING_REQUIRES_MULTITENANCY",
  "message": "Billing service only enabled in multi-tenant (advanced/full) mode. Enable multitenancy first.",
  "traceId": "fa11ed",
  "doc": "https://docs.openstrata.cc/errors/BILLING_REQUIRES_MULTITENANCY"
}
```

### 1.5 Business Error Codes

| Code | HTTP | Description |
| --- | --- | --- |
| `BILLING_REQUIRES_MULTITENANCY` | 422 | Billing called without multi-tenancy enabled |
| `INVOICE_NOT_FOUND` | 404 | Invoice does not exist |
| `INVOICE_ALREADY_FINALIZED` | 409 | Duplicate settlement for same period |
| `BUDGET_NOT_FOUND` | 404 | Budget not set for tenant |
| `BUDGET_EXCEEDED` | 409 | Budget limit reached, circuit-break activated |
| `METERING_FORMAT_INVALID` | 400 | Metering event format invalid |
| `PRICE_RULE_NOT_FOUND` | 404 | No price rule for dimension |

## 2. Data Model

### 2.1 Database

| Attribute | Value |
| --- | --- |
| Engine | PostgreSQL 16.0 (core, §16 base) |
| Schema | `billing` (shared) |
| Multi-tenant isolation | `tenant_id` column + RLS (§8.2) |
| ORM | JPA (Hibernate 6 / Jakarta Persistence) |
| Money storage | `BIGINT` in smallest currency unit (cents); no JSONB for money |
| Migration | Flyway (`V1__billing_init.sql`, `V2__rls.sql`) |

### 2.2 Table DDL

```sql
-- Usage Records
CREATE TABLE usage_records (
  record_id    VARCHAR(64) PRIMARY KEY,
  tenant_id    VARCHAR(64) NOT NULL,
  app_id       VARCHAR(64),
  model        VARCHAR(64),
  dimension    VARCHAR(24) NOT NULL,     -- TOKEN_INPUT/TOKEN_OUTPUT/GPU_HOUR/VECTOR_COUNT/API_CALL/AGENT_RUN
  amount       BIGINT      NOT NULL,
  occurred_at  TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_usage_tenant_day ON usage_records(tenant_id, occurred_at);

-- Price Rules
CREATE TABLE price_rules (
  rule_id    VARCHAR(64) PRIMARY KEY,
  dimension  VARCHAR(24) NOT NULL,
  unit_price BIGINT      NOT NULL,        -- smallest currency unit (point)
  currency   VARCHAR(8)  NOT NULL DEFAULT 'CNY',
  effective  TIMESTAMPTZ NOT NULL
);

-- Invoices
CREATE TABLE invoices (
  invoice_id   VARCHAR(64) PRIMARY KEY,
  tenant_id    VARCHAR(64) NOT NULL,
  period       VARCHAR(16) NOT NULL,       -- 2026-07 (monthly) / 2026-07-17 (daily)
  total        BIGINT      NOT NULL,
  currency     VARCHAR(8)  NOT NULL,
  status       VARCHAR(16) NOT NULL DEFAULT 'DRAFT',
  finalized_at TIMESTAMPTZ
);

-- Invoice Lines
CREATE TABLE invoice_lines (
  line_id     VARCHAR(64) PRIMARY KEY,
  invoice_id  VARCHAR(64) NOT NULL REFERENCES invoices(invoice_id),
  dimension   VARCHAR(24) NOT NULL,
  quantity    BIGINT NOT NULL,
  unit_price  BIGINT NOT NULL,
  subtotal    BIGINT NOT NULL
);

-- Allocations
CREATE TABLE allocations (
  alloc_id    VARCHAR(64) PRIMARY KEY,
  invoice_id  VARCHAR(64) NOT NULL REFERENCES invoices(invoice_id),
  cost_center VARCHAR(64) NOT NULL,
  amount      BIGINT NOT NULL
);

-- Budgets
CREATE TABLE budgets (
  budget_id   VARCHAR(64) PRIMARY KEY,
  tenant_id   VARCHAR(64) NOT NULL UNIQUE,
  limit_val   BIGINT NOT NULL,
  spent       BIGINT NOT NULL DEFAULT 0,
  threshold   NUMERIC(5,2) NOT NULL DEFAULT 0.8
);
```

### 2.3 JPA Entity Mapping

| Entity | Table | Notes |
| --- | --- | --- |
| `UsageRecordEntity` | `usage_records` | Idempotent by `record_id` |
| `PriceRuleEntity` | `price_rules` | `unit_price` is `BIGINT` (points) |
| `InvoiceEntity` | `invoices` | Immutable after `FINALIZED` |
| `InvoiceLineEntity` | `invoice_lines` | References `invoices` |
| `AllocationEntity` | `allocations` | References `invoices` |
| `BudgetEntity` | `budgets` | One per tenant (UNIQUE) |

### 2.4 Value Object Column Types

| Domain VO | DB Column | Type |
| --- | --- | --- |
| `UsageDimension` | `usage_records.dimension`, `price_rules.dimension` | `VARCHAR(24)`, enum |
| `Money` | `invoices.total`, `price_rules.unit_price`, `budgets.limit_val` | `BIGINT` (smallest currency unit) |
| `Period` | `invoices.period` | `VARCHAR(16)` |
| `InvoiceStatus` | `invoices.status` | `VARCHAR(16)`, enum: DRAFT/FINALIZED/SENT |
| `AlertThreshold` | `budgets.threshold` | `NUMERIC(5,2)`, default 0.8 |

## 3. Configuration

### 3.1 Service Configuration

```yaml
openstrata:
  service:
    port: 8084
  features:
    billing:
      enabled: false              # default off; only when multitenancy lit
    budgetAlert:
      enabled: true
      threshold: 0.8
    showback:
      enabled: true               # department allocation
  pricing:                        #internal transfer prices (in smallest unit, e.g., cents)
    token_input:  2               # per 1M tokens
    token_output: 6
    gpu_hour:     15              # A100 80G
    vector_1m:    0.5
    doc_gb:       0.1
    api_10k:      0.5
  spi:
    auth:   { provider: keycloak }
    cache:  { provider: redis }   # valkey alternative
    metering:
      source: [ai-gateway-core, opencost]
```

### 3.2 Profile → Feature Matrix

| Profile | billing.enabled | budgetAlert | showback | Deployed |
| --- | --- | --- | --- | --- |
| starter | false | — | — | No |
| standard | false | — | — | No |
| advanced | true | true | true | Yes |
| full | true | true | true | Yes |
